### 📌 Projetos

#### 📚 [Biblioteca Monsa](https://github.com/sandersonElias/Gerenciador_Biblioteca)
Sistema fullstack para gerenciar acervo, empréstimos, reservas e usuários de uma biblioteca escolar. Em implantação na Escola Estadual Monsenhor Horta.
- API REST em **Java 21 + Spring Boot** com autenticação **JWT**, BCrypt e Spring Security
- 3 perfis de acesso: administrador, funcionário e aluno
- **PostgreSQL** com migrações versionadas pelo **Flyway**
- Controle de cada exemplar (cópia física), fila de reservas e rotinas agendadas (`@Scheduled`)
- Front-end em React + TypeScript · Deploy: Vercel + Railway (Docker)
- Relatório técnico de 27 páginas
- 🔗 [Back-end](https://github.com/sandersonElias/Back-End_GerenciadorBiblioteca) · [Front-end](https://github.com/sandersonElias/Front-End_GerenciadorBiblioteca) · [Demo](https://biblioteca-monsa.vercel.app)

#### 🐦 Twittus
API REST de uma rede social estilo mini Twitter, feita para estudar segurança em Spring: OAuth2 Resource Server, JWT com chaves RSA e autorização por escopos. MySQL em Docker e front-end em React + TypeScript.

#### 🚂 [Maquete Industrial](https://github.com/sandersonElias/Maquete_Industrial)
Maquete ferroviária e industrial em escala HO para a feira de ciências: caminhões basculantes controlados por Arduino (Bluetooth HC-05) e por um app Android em Kotlin com joystick, peças impressas em 3D.
